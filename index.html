Dashboard Kependudukan & Sinkronisasi Header Real-Time

Header di bagian atas menyatu dengan aplikasi utama dan tersinkron ke semua perangkat melalui Firebase Firestore.

Proyek: dasbor-rt

1. Edit Jarak Jauh (Remote)

Buka panel Remote Header dari HP atau laptop admin, masukkan PIN, lalu ubah judul, pengumuman, atau tambahkan gambar baru.

2. Tayang Otomatis di Semua User

Saat tombol Simpan & Tayangkan ke Semua User ditekan, data dikirim ke Firestore dan langsung memperbarui layar seluruh pengunjung tanpa *refresh*.

3. Unggah Foto & URL Gambar

Mendukung penambahan banyak gambar sekaligus dalam bentuk slideshow otomatis, baik melalui tautan gambar maupun unggahan file foto dari galeri perangkat.
