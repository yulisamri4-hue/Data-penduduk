Prompt Instalasi Browser Tersedia

Ketuk tombol di samping untuk memunculkan dialog instalasi aplikasi di perangkat Anda.

Android (Chrome): Jika tombol Instal Sekarang muncul, ketuk tombol tersebut. Jika tidak, ketuk menu titik tiga (⋮) di pojok kanan atas lalu pilih Tambahkan ke layar utama atau Instal aplikasi.

iPhone / iPad (Safari): Ketuk ikon Bagikan (kotak dengan panah ke atas) lalu gulir ke bawah dan pilih Tambah ke Layar Utama.

Jika dibuka langsung sebagai file lokal (file://): Browser membatasi Service Worker dan prompt instalasi otomatis pada protokol file://. Untuk pengalaman PWA penuh dan cache offline Service Worker, jalankan file ini melalui server lokal (misalnya VS Code Live Server, npx serve, atau python3 -m http.server) atau hosting HTTPS.
